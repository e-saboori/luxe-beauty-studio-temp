Image folders for easy updates:

- `home-hero.jpg`: main Home page hero photo.
- `about`: owner portraits, studio photos, and About page rotating images.
- `lash`: lash extension photos.
- `eyebrows`: brow shaping and microblading photos.
- `lip`: lip blush photos.
- `lib`: kept because it was requested; use `lip` for lip photos unless you prefer this folder name.
- `eyeline`: kept because it was requested; use `eyeliner` for eyeliner photos unless you prefer this folder name.
- `eyeliner`: eyeliner shading and permanent makeup photos.

Current naming convention is lowercase kebab-case, for example `artist-portrait.jpg`, `classic-lash-result.jpg`, and `lip-blush-result.jpg`.

After adding images, update the relevant image paths in `lib/site-data.ts`.
